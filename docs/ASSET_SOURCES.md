# Sumber Aset — Sela

Semua foto pada aplikasi adalah **foto ilustrasi** yang dibundel secara lokal.
Foto tersebut bukan foto tempat nyata yang disebut pada data, karena seluruh
nama tempat, alamat, harga, dan jam operasional di `assets/data/places.json`
adalah data fiktif untuk praktikum.

## Font

| Keluarga | Berkas | Sumber | Lisensi |
|---|---|---|---|
| Newsreader | `assets/fonts/Newsreader.ttf` | Google Fonts (`google/fonts`, berkas variabel `Newsreader[opsz,wght].ttf`) | SIL Open Font License 1.1 |
| Inter | `assets/fonts/Inter.ttf` | Google Fonts (`google/fonts`, berkas variabel `Inter[opsz,wght].ttf`) | SIL Open Font License 1.1 |

Keduanya disertakan sebagai berkas agar aplikasi tidak mengunduh font saat
dijalankan. Lisensi OFL mengizinkan penyertaan dalam aplikasi, termasuk
penggunaan komersial, dengan syarat berkas lisensi tidak diubah dan nama
cadangan font tidak dipakai untuk versi modifikasi.
